# ML Vision Broadband - Claude Code Instructions

## Project Overview

Computer vision analysis of Google Street View images to predict broadband usage across Nebraska ZIP codes. This project explores whether visual features of built environments (infrastructure, development patterns) can supplement rural-urban typology (RUCA) in predicting broadband adoption.

**Manuscript Title**: See `manuscript_quarto/` (do not treat the manuscript as pipeline output).

## Quick Start

```bash
# Activate virtual environment
source .venv/bin/activate

# Run full pipeline
python src/pipeline.py run_all

# Or run individual stages
python src/pipeline.py ingest_data      # Stage 00: Load data
python src/pipeline.py link_records     # Stage 01: Link images to ZIPs
python src/pipeline.py build_panel      # Stage 02: Extract CV features
python src/pipeline.py run_estimation   # Stage 03: Train models
python src/pipeline.py estimate_robustness  # Stage 04: Robustness checks
python src/pipeline.py make_figures     # Stage 05: Generate figures
python src/pipeline.py validate_manuscript  # Stage 06: Validate manuscript
```

## Key Methodological Constraints

### CRITICAL: Always Use Spatial Cross-Validation

**Random CV causes data leakage** due to spatial autocorrelation. Neighboring ZIP codes have similar broadband adoption rates, so random train/test splits allow the model to "cheat" by learning geographic patterns.

- **Always use**: `SpatialCVManager` from `src/utils/spatial_cv.py`
- **Quantify leakage**: use `data_work/diagnostics/robustness_results.csv`
- **Do not hardcode metrics**: use `data_work/diagnostics/estimation_results.csv`

### Regularization Requirements

Visual features require strong regularization to prevent overfitting:
- **Visual model**: Ridge α=100 (see `src/config.py`)
- **RUCA model**: Ridge α=1.0 (see `src/config.py`)

## Data Locations

### Raw Data (`data_raw/`) - Canonical
- `manifest/`: Image manifest CSVs
- `labels/`: Broadband usage labels with RUCA codes
- `images/`: Not used; `IMAGES_DIR` points to the archive corpus (7,619 images across 261 ZCTA directories)

### Processed Data (`data_work/`) - Canonical
- `data_raw.parquet`: Stage 00 output
- `data_linked.parquet`: Stage 01 output
- `panel.parquet`: Analysis-ready panel (Stage 02)
- `features/`: Extracted visual features
- `models/`: Trained model artifacts
- `diagnostics/`: Analysis outputs and quality reports

### Figures (`manuscript_quarto/figures/`)
- Publication-ready figures generated by Stage 05

## Feature and RUCA Definitions

- Visual feature names: `src/config.py` (`VISUAL_FEATURE_NAMES`)
- RUCA categories/groups: `src/config.py` (`RUCA_CATEGORIES`, `RUCA_GROUPS`)

## Important Notes

1. **Image directory**: Images are at `archive/images_legacy/enhanced_processed/images_enhanced_processed/` (configured in `src/config.py`)
2. **Precomputed features**: Check `data_work/features/` before recomputing
3. **Spatial groups**: Use 5 groups based on ZIP code geography
4. **Two-stage model**: Fit RUCA first, then visual on residuals
5. **Legacy docs**: Pre-CENTAUR text dumps live in `doc/logs/`
