# Review Documentation

Use review IDs (for example, SR-001) rather than dates in filenames.
If the user references SN-001, treat it as an alias for SR-001 unless explicitly renaming the scheme.

- Summary: `doc/reviews/PEER_REVIEW_<ID>.md`
- Response: `doc/reviews/PEER_REVIEW_RESPONSE_<ID>.md`
- Full text: `doc/logs/peer_review_<id>.md`

Record the review date inside each file.
Track status (current vs superseded) in the intake/response files and in doc/reviews/INDEX.md.
