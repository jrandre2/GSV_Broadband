# Legacy Logs

This folder stores large text dumps (including peer review inputs) and legacy logs. These files are not canonical.

Use review IDs (e.g., `peer_review_sr001.md`) instead of dates for review log filenames.

Current sources of truth:
- Pipeline outputs in data_work/diagnostics/
- Pipeline stages in src/pipeline.py and src/stages/
- Methods in doc/METHODOLOGY.md
